# Lezioni apprese

Registro delle lezioni degli sprint: cosa è successo, cosa abbiamo imparato,
cosa è cambiato. Una voce si scrive alla chiusura di uno sprint, solo se c'è
una lezione vera.

Come si scrive una voce: in cima al file, sotto questa introduzione, la più
recente per prima. Una lezione per voce, senza segreti, con link alle prove.

```
## AAAA-MM-GG — Titolo breve della lezione
- **Cosa è successo:** i fatti, in due righe.
- **Lezione:** la regola generale che ne ricaviamo.
- **Cosa è cambiato:** il controllo, la regola o il codice che la applica (link).
- **Stato:** applicata | da fare | in prova
```
